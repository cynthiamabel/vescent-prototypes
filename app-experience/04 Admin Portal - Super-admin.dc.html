⚑ DISCUSSION ITEM
Retire the secret word?
The secret word was a gatekeeper + scarcity precaution when we had little bad-actor security. With the pay model, delivering a secret word to parents after purchase is impractical. Open question for Eric: does single sign-on / magic-link login give us enough security on its own, or do we still issue parents a code after payment?
Option A · SSO / magic link
Parent pays → email magic link or 6-digit code → teen logs in. Less friction; security from the login itself.
Option B · Issued code
Keep an entry code, delivered post-payment. Extra gate, but a delivery + support burden.
